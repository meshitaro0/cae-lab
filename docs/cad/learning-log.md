## 2026-09-27 — トラック設計

### 対象

- ロードマップ：[ROADMAP.md](ROADMAP.md)

### 設計前の確認（学習者の回答）

- **実務でのCADとの接点**：受け取った形状をCAE用に処理する。CAE自動化に形状を組み込みたい。
- **最も手に入れたいもの**：形状表現の数理の理解（第一）、コードCAD＋CAE自動化。
- **学習環境**：Pythonのオープンソースのみ。
- **1 Phaseの分量**：固体力学トラックのPhase 4・6程度。

### 設計判断

- 固体力学トラックの「出力から逆算する」構成を入力側へ向け、各Phaseを前処理・自動化で起きる症状から始める。
- 数理を軸にするため、Phase 1〜3はNumPyで曲線・曲面・トポロジを自作実装し、build123d・gmshはその後に「中身を知っている道具」として導入する。
- Phase 4で作るブラケットを、Phase 5〜8で使い続ける題材にする。解析は平面応力に限り、NumPyだけの自作ソルバで完結させる。
- サロゲートモデルは実務経験があるため手法の解説を省き、形状に固有の不連続・失敗・メッシュノイズに集中する。
- 最終Phaseを等幾何解析とし、Phase 1のB-spline基底と固体力学Phase 4の形状関数を合流させる。
- 固体力学トラックの「次回の教材設計方針」（関数引数と共通条件の区別、定型処理の配布、比較量の式による指定）を初回から適用する。
- 環境：Windows・Python 3.12で build123d 0.13.0 と gmsh 4.15.2 の依存解決を確認した（インストールはPhase 3で行う）。

- 順序・分量について：よいと思う。
