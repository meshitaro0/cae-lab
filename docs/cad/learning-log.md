## 2026-09-27 — Phase 1 初稿

### 対象

- 本文：[phase1-curves.md](texts/phase1-curves.md)
- 演習：[Phase1.ipynb](../../notebooks/cad/Phase1.ipynb)

### 初稿の内容と反映判断

- STEPの `B_SPLINE_CURVE_WITH_KNOTS` の行を入口にし、Bézier（de Casteljau）→ B-spline（Cox–de Boor）→ 1次B-splineとFEMの形状関数 → 多重度と連続性（$C^k$／$G^k$）→ ノット挿入 → STEPの各引数の解読、の順に構成した。
- 幾何学への苦手意識への対応：全体を「制御点の重み付き平均」という一つの見方で通し、曲線の性質を重みの性質（1の分割・非負・局所台）から数値で確かめる構成にした。コードで生成した図を4枚入れ、演習では描画関数を配布した（図は任意）。
- 固体力学トラックとの接続：1の分割と剛体並進、線形精度とパッチテスト、局所台と剛性行列の帯幅を対応付けた。
- 演習は5問・100点。関数の入出力契約・`_ref` の用途・比較量の式・許容値（座標の大きさ $s$ に対する相対値）を問題文で指定した。入力検査、スパン探索、Bernstein形式の評価、全基底の並べ替え、描画は配布した。
- 検証：演習の全課題を模範実装で解き、配布状態（未実装）で全セルがエラーなく動くこと、配布の入力検査を残したまま模範実装で全チェックが通ることを確認した。STEPの例は $\mathbf C(0.25)=(15,\ 19.6875,\ 0)$。多重度 $k=1,2,3$ で跳ぶ導関数は、それぞれ3階・2階・1階。多重度3へのノット挿入後も跳ぶのは3階だけ。この確認で見つかった配布コードの不具合（0次の導関数曲線を検査で拒否していた）は、配布前に修正した。
- 用語集：B-spline基底とノットベクトル、ノット多重度と連続性、パラメトリック連続と幾何的連続を追加した。
- PROFILE：更新なし。
