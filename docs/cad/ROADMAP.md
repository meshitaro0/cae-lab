# CADトラック：メッシュの手前を逆算する — 形状表現からCAE自動化まで

## このトラックの問い

> 受け取ったCAD形状は、何で表現されていて、どこで近似され、その近似が解析結果と自動化にどう効くのか。

固体力学トラックでは、CAEの出力値から力学と離散化へ逆算した。このトラックでは、その**入力側**へ逆算する。
設計部門から届くSTEPファイルの中身から始め、曲線・曲面の数理、ソリッドのつながり方（トポロジ）、パラメトリック形状、メッシュ化、CAE向けの形状処理、自動化パイプラインまでを一本の線でつなぐ。最後に、CADの基底関数をそのまま解析に使う等幾何解析（IGA）で、二つのトラックを合流させる。

CAD操作の習熟ではなく、**形状の上で何が起きているかを自分の実装で確かめ、CAE前処理と自動化の判断を根拠付きで語れること**を目標にする。

## 学習の流れ

| Phase | 入口の症状（実務） | 中心の問い | 主な成果 |
| --- | --- | --- | --- |
| 1. 曲線 | STEPを開くと、エッジが `B_SPLINE_CURVE_WITH_KNOTS` と書かれている | CADの曲線はなぜ多項式を貼り合わせるのか | Bézier・B-splineの自作評価器、ノットと連続性 |
| 2. NURBSと曲面 | 円筒面が `RATIONAL` 付きで出力される | 円はなぜ有理式でないと正確に描けないか | NURBS曲線・曲面、法線・曲率の計算 |
| 3. B-rep | インポートで「隙間」「非多様体エッジ」の警告が出る | ソリッドは何でできていて、何が壊れるのか | トポロジの走査と、壊れた形状の診断器 |
| 4. パラメトリック形状 | 寸法を変えたら、境界条件を貼った面の番号が変わった | 履歴と形状の関係はどうなっていて、何が自動化を壊すか | build123dによるパラメトリック部品と頑健な面選択 |
| 5. メッシュ化 | 曲面の要素が粗い／品質チェックで警告が出る | 形状の近似誤差と要素品質は解析精度にどう効くか | gmsh連携、要素品質の自作評価、2D三角形要素 |
| 6. CAE向け形状処理 | 小さな穴・フィレットを消してよいか判断を迫られる | 簡略化・特異点・中立面は関心量をどう変えるか | 形状処理ごとの関心量への影響評価 |
| 7. 自動化パイプライン | パラメータを振ると一部のケースが失敗・異常値になる | 形状パラメータからサロゲートまでをどう頑健につなぐか | 形状→メッシュ→解析→サロゲートの自動化 |
| 8. 等幾何解析（IGA） | CAD→メッシュ変換でいつも形状が近似される | CADの基底でそのまま解けないか | NURBS基底による1D・2D解析、Phase 5のFEMとの比較 |

目安として、固体力学トラックの実績（6 Phaseを約3.5週間）から、1 Phaseあたり3〜5日を見込む。Phase 8（IGA）は、2026-09-27の意見を受けて必須のまま進める。

## 幾何学への足場

幾何学に苦手意識があるという意見（2026-09-27）を受け、次を全Phaseの設計に適用する。一回の意見なので[PROFILE.md](../PROFILE.md)には昇格せず、Phase 1・2のログで効果を確かめる。

- **見方を一つに絞る**：曲線・曲面は「制御点の重み付き平均」、トポロジは「つながりの表」、メッシュ品質は「写像のヤコビアン」として、線形代数と数値計算の言葉に置き換えてから幾何の意味を述べる。
- **図を先に**：新しい幾何概念は、本文の図（コードで生成）で形を見せてから式へ進む。演習には描画関数を配布し、形の確認を任意で行えるようにする。
- **性質は数値で確かめる**：凸包性・連続性・曲率などを図の印象ではなく、式で定義した比較量で合否判定する。解析値が分かる形状（直線・円・円筒・球）で検証してから一般形状へ進む。
- **微分幾何は必要な分だけ**：Phase 2の曲率は、円の曲率 $1/R$ から始め、主曲率は計算手順と検証に重点を置く。一般論の証明は求めない。

## 各Phaseの内容

### Phase 1. 曲線：点列からB-splineへ

- **扱う内容**：Bernstein基底とde Casteljauのアルゴリズム、B-spline基底（Cox–de Boorの漸化式）、ノットベクトル、局所台と1の分割、ノット多重度と連続性（$C^k$ と $G^k$ の区別）、ノット挿入。
- **固体力学との接続**：Phase 4の1次形状関数（ハット関数）は、節点をノットとする1次B-spline基底そのものである。形状関数の「1の分割」がなぜ剛体並進を正しく表すために必要だったかを、曲線の側から見直す。
- **演習の核**：Cox–de Boorの評価器を実装し、1の分割・ノット挿入で曲線が変わらないこと・多重度と連続性の関係を数値で確認する。
- **予告**：有理化（Phase 2）と、この基底を解析に使うこと（Phase 8）。

### Phase 2. NURBSと曲面：円はなぜ有理式でないと描けないか

- **扱う内容**：重み付き制御点と射影的な解釈、円弧の厳密表現（四分円は制御点3つ、重み $1,\ \tfrac{\sqrt2}{2},\ 1$）、テンソル積曲面、偏導関数・法線、第一・第二基本形式と主曲率。
- **CAEとの接続**：フィレット半径（曲率）は応力集中を支配する形状量である。多項式近似の円とNURBSの円の差が、Phase 5の形状近似誤差の出発点になる。
- **演習の核**：多項式B-splineで近似した円とNURBSの円の半径誤差を比較する。円筒・球などの主曲率を自作コードで求め、解析値で検証する。

### Phase 3. B-rep：ソリッドは「面の集まり＋つながり方」

- **扱う内容**：頂点・エッジ・ループ・面・シェル・ソリッドの階層と向き、トリム曲面とパラメータ空間上の曲線、Euler–Poincaréの式、多様体性と水密性、OpenCascadeの許容差（トレランス）。
- **ツール導入**：ここからbuild123dを使い、実際のB-repを走査する。自作の小さなトポロジ表現と突き合わせて、ツールの出力の意味を確認する。
- **CAEとの接続**：STEPインポート時の隙間・細長い面（スライバー）・非多様体エッジが、なぜメッシュ生成の失敗につながるか。
- **演習の核**：オイラー標数や、各エッジに接する面の数から、開いたシェルや非多様体を検出する診断関数を作る。意図的に壊した形状で診断器を検証する。

### Phase 4. パラメトリック形状：履歴は形状ではない

- **扱う内容**：スケッチ→押し出し・回転→フィレット・面取り→ブーリアン演算の流れ、設計意図とパラメータ、拘束。トポロジカルネーミング問題（寸法変更で面・エッジの番号が変わる理由）。STEP出力と読み戻し。
- **題材**：このトラック全体で使う**穴とフィレット付きのブラケット**を、パラメータを受け取る関数として作る。
- **CAEとの接続**：自動化で境界条件・荷重面を面番号で指定すると、寸法変更で壊れる。面を幾何条件（法線・位置・面積）で選ぶ設計に替える。
- **演習の核**：`make_bracket(params)` の実装、体積・表面積の解析値による検証、パラメータを変えても同じ面を選べる選択関数の設計と試験。

### Phase 5. メッシュ化：形状近似と要素品質

- **扱う内容**：表示用のテッセレーションと解析用メッシュの違い、弦高（サジッタ）許容値と分割数（弦長 $c$ に対する弦高 $s\approx c^2/(8R)$）、gmshのサイズ制御、物理グループによる境界条件の受け渡し、要素品質指標（最小角・アスペクト比・ヤコビアン比）。
- **固体力学との接続**：Phase 4の自然座標とヤコビアンを2Dの定ひずみ三角形要素（CST）へ広げ、平面応力の小さなソルバを作る。要素の形が悪いと、何が悪化するのか（剛性行列の条件数、ひずみの近似）を、要素品質指標と結び付ける。
- **演習の核**：弦高許容値と分割数の関係を導いて確かめる。要素品質を自作コードで評価しgmshの値と比較する。CSTの要素剛性を実装し、組立・求解の配布コードと合わせて、円孔付き板の応力をKirschの解析解と比べる。
- **設計上の注意**：組立・求解・入力検査などの定型部分は配布し、形状近似の誤差評価と要素の実装を自力設計の中心にする。

### Phase 6. CAE向け形状処理：何を消し、何を残すか

- **扱う内容**：簡略化（小穴・フィレット・面取りの除去）、フィレット半径と応力集中、鋭い入隅の応力特異性（直角の入隅では応力が $r^{-0.46}$ 程度で発散する）、対称性の利用、薄肉部品の中立面とシェルモデル化の考え方。
- **固体力学との接続**：Phase 6の演習で角部Misesが収束しなかった現象を、形状側の原因として説明し直す。
- **演習の核**：Phase 4のブラケットで、フィレット半径を変えた場合と除去した場合の関心量（最大応力・剛性）の変化を、メッシュ収束と合わせて評価する。簡略化してよい条件を関心量ごとに判断する。
- **範囲**：中立面の自動抽出アルゴリズムは扱わず、どの面の対が中立面になるか、どこで板厚が変わるかの判断に絞る。

### Phase 7. 自動化パイプライン：形状パラメータからサロゲートまで

- **扱う内容**：パラメータ→形状→STEP→メッシュ→解析→関心量の流れ、再生成失敗・メッシュ失敗の扱い（欠損として記録するか、設計空間の制約とするか）、形状の実行可能領域（穴が縁に届く等）、トポロジ変化による関心量の不連続、パラメータ変更でメッシュが変わることによる応答のノイズ、再現性とキャッシュ。
- **学習者の強みの活用**：サロゲートモデル自体は実務経験があるため手法の解説は最小限にし、**形状に固有の難しさ**（不連続・失敗・メッシュノイズ）がサロゲートの品質に与える影響に集中する。
- **演習の核**：ブラケットの実験計画を回し、失敗ケースを分類し、各ケースでのメッシュ収束を確認したうえで最大応力・質量のサロゲートを作る。不連続を含む領域での予測誤差を評価する。

### Phase 8. 等幾何解析（IGA）：CADの基底でそのまま解く

- **扱う内容**：Phase 1・2のB-spline/NURBS基底を、Phase 4（固体力学）の形状関数の代わりに使う。h・p・k細分化、パラメータ空間から物理空間への写像、境界条件の課し方。
- **二つのトラックの合流**：1Dバーは固体力学Phase 4の構成をそのまま再利用する。2Dでは円孔付き板を**円を厳密に表したまま**解き、Phase 5のCSTと同じ自由度数で精度を比べる。
- **演習の核**：基底の評価と写像のヤコビアンを実装し、組立は配布コードを使う。Kirschの解との誤差収束を、細分化の種類ごとに比較する。
- **修了時に語れること**：「CAD→メッシュ変換で何が失われ、IGAはどこまでそれを解消し、何が解消できないのか（トリム曲面・複数パッチ）」。

## トラック全体を貫く題材

Phase 4で作る**穴とフィレット付きのブラケット**を、Phase 5〜8で使い続ける。1回の演習で作った関数が次のPhaseの部品になるため、トラックの終わりには「寸法を入れると形状・メッシュ・応力・サロゲートまで返す」一続きのコードが手元に残る。解析は板厚一定の平面応力に限り、NumPyだけの自作ソルバで完結させる。

## 固体力学トラックから引き継ぐ演習設計

[固体力学トラックのロードマップ](../solid-mechanics/ROADMAP.md)の「次回の教材設計方針」を、このトラックの初回から適用する。

- 共通試験条件（例：`R_ref`、`tol_ref`）と関数引数を名前と説明で区別し、外側の定数を使ってよい範囲を明示する。
- 定型の入力検査・組立・描画は配布し、自力設計は検証条件と形状・物理の判断に集中させる。

- 用語集にある語は、初出で用語集へリンクする。
