# CAE結果から逆算する固体力学カリキュラム

## 設計原則

対象は、FEMを使えるが理論が断片化しているCAE技術者である。各 Phase は「CAEで既に見ている量」から始め、**直感 → 定義 → 導出 → 数値実験 → FEMでの所在 → 適用限界**を往復する。大量の公式演習は置かず、各節に「なぜそう定義するのか」と「この値をそのまま信じてよいか」の問いを置く。

| Phase | 中心の問い | 主な成果物 |
| --- | --- | --- |
| 1. 応力・ひずみ | コンターの一色は何か | 線形弾性の局所材料点計算、結果レビュー表 |
| 2. テンソル・不変量 | 主応力や Mises は何を捨て、何を残すか | 座標変換・Mohr円・不変量のノートブック |
| 3. 材料力学の再導出 | 軸・曲げ・ねじり・座屈は、なぜこの式か | 梁・軸部材を仮定から導く計算実験 |
| 4. FEM | なぜ `K = integral(B^T D B)` になるか | 1Dバーから2D要素へ進む最小FEM |
| 5. 塑性 | 相当応力・相当塑性ひずみは何か | J2弾塑性の材料点更新（return mapping） |
| 6. 実務CAE | 出力値の根拠と限界をどう評価するか | LS-DYNA等の結果レビュー用チェックリスト |

## 各章の固定フォーマット

1. **現場の問い**：コンター、破損、拘束、メッシュ、材料カードの具体例。
2. **最小モデル**：現象を表すのに必要な仮定を明示する。
3. **導出**：式の出発点と、何を捨てたかを追う。
4. **数値実験**：Pythonで極限・対称性・スケーリングを確認する。
5. **FEM上の位置**：未知量、積分点、要素、材料更新のどこに対応するか。
6. **適用限界**：線形化、要素品質、特異点、出力平均化などを点検する。
7. **説明課題**：数値の正誤でなく、物理的に説明させる。

## 最初の4本の教材

1. **応力コンターは何の値か**：積分点・外挿・平均と特異点。
2. **単軸引張を3Dから作り直す**：応力状態とひずみ状態、Poisson効果、拘束。
3. **主応力は固有値問題である**：座標変換と破壊・降伏基準の使い分けへの入口。
4. **Mises応力を保留する理由**：偏差応力と不変量を導くための問題設定。

この順序により、Mises応力を「表示ボタンの出力」から、J2塑性へつながる必然的な指標へ移す。
