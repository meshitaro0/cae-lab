# Phase 2 — テンソル・主値・不変量：von Mises 応力を座標に依らず読む

## 入口：コンターの一つの数値は何を捨てているか

応力の各成分は座標軸を回すと変わる。一方、材料の降伏評価に使う量が座標の取り方で変わってはならない。本Phaseの問いは次である。

> 応力テンソルから、座標系に依らない主応力と von Mises 応力をどう作るか。

本文では応力を例にするが、対称なひずみテンソルにも同じ考え方が使える。演習は [Phase 2 演習ノートブック](../../notebooks/Phase2.ipynb) で行う。

## 1. 座標を回すと成分は変わる

直交基底を回す回転行列を $\mathbf{Q}$ とする。$\mathbf{Q}^T\mathbf{Q}=\mathbf{I}$ を満たし、基底ベクトルを列に並べる約束では、同じ応力状態の新しい座標成分は

```math
\boldsymbol{\sigma}'=\mathbf{Q}^T\boldsymbol{\sigma}\mathbf{Q}
```

となる。$\boldsymbol{\sigma}$ と $\boldsymbol{\sigma}'$ は別の応力状態ではない。面の向きと座標軸の記述を変えただけである。例えば単軸応力でも、軸を斜めに取ればせん断成分が現れる。

$\boldsymbol{\sigma}$ は二階テンソル、$\mathbf{Q}$ は $3\times3$ の直交行列、$\mathbf{I}$ は二階単位テンソルである。この変換は直交座標系での回転を対象にする。大変形での応力測度や物質座標への写像は扱わない。

## 2. 主応力と最大せん断応力

対称な応力テンソルでは、直交する固有ベクトル $\mathbf{q}_i$ を主軸に選べる。

```math
\boldsymbol{\sigma}\mathbf{q}_i=\sigma_i\mathbf{q}_i,
\qquad
\mathbf{Q}=[\mathbf{q}_1\ \mathbf{q}_2\ \mathbf{q}_3]
```

このとき $\mathbf{Q}^T\boldsymbol{\sigma}\mathbf{Q}=\mathrm{diag}(\sigma_1,\sigma_2,\sigma_3)$ であり、非対角成分（せん断応力）は消える。固有値 $\sigma_i$ が主応力である。順序はソフトウェアごとに確認する。ここでは $\sigma_1\ge\sigma_2\ge\sigma_3$ とする。

主応力は座標系を変えても変わらない。三次元の最大せん断応力は

```math
\tau_{\max}=\frac{\sigma_1-\sigma_3}{2}
```

である。これは最大・最小主応力の中間方向を法線にもつ面で生じる。脆性破壊、延性降伏、疲労などの判定基準が同じとは限らないため、この値だけで材料の安全性は判定しない。

この式は主軸座標での面の回転からも読める。最大・最小主応力方向を含む平面で、主軸から角度 $\theta$ をなす面のせん断応力は

```math
\tau(\theta)=\frac{\sigma_1-\sigma_3}{2}\sin(2\theta)
```

となる。$\theta=45^\circ$ で絶対値が最大になり、上式を得る。これはMohrの円の半径と同じ内容である。三次元では、任意の面での最大値が最大・最小主応力の組で決まる。

対称行列が直交する固有ベクトルで対角化できることはスペクトル定理による。より正確には、実対称行列では固有値が重複していても各固有空間内で直交規格化できるため、全体として正規直交固有基底を選べる。これは「対称であること」の十分条件であり、一般の非対称行列には保証されない。

## 3. 静水圧成分と偏差成分

平均応力（静水圧応力）$p$ を、引張を正とする本教材の符号規約で

```math
p=\frac{1}{3}\mathrm{tr}(\boldsymbol{\sigma})
```

と定義する。$p\mathbf{I}$ は全方向に等しい引張・圧縮の成分である。地盤・流体では圧縮を正に取る流儀もあり、その場合の圧力記号とは符号が逆になり得る。

偏差応力テンソル $\mathbf{s}$ は

```math
\mathbf{s}=\boldsymbol{\sigma}-p\mathbf{I},
\qquad \mathrm{tr}(\mathbf{s})=0
```

である。静水圧成分は体積変化に、偏差成分は形状変化に関係する。金属の J2（von Mises）塑性では、静水圧成分ではなく偏差応力の大きさが降伏開始に関与する。これは等方・延性金属の近似であり、圧力依存性をもつ材料、脆性材料、異方性材料にはそのまま適用できない。

## 4. 不変量と von Mises 応力

座標回転で変わらないスカラーを不変量という。応力テンソルの第1不変量は $I_1=\mathrm{tr}(\boldsymbol{\sigma})$、偏差応力の第2不変量は

```math
J_2=\frac{1}{2}\mathbf{s}:\mathbf{s}
```

である。$\mathbf{A}:\mathbf{B}=\sum_{i,j}A_{ij}B_{ij}=\mathrm{tr}(\mathbf{A}^T\mathbf{B})$ は二階テンソルの内積であり、ここではスカラーを返す。von Mises 相当応力は

```math
\sigma_{\mathrm{vm}}=\sqrt{3J_2}=\sqrt{\frac{3}{2}\mathbf{s}:\mathbf{s}}
```

と定義される。主応力からは

```math
\sigma_{\mathrm{vm}}
=\sqrt{\frac{(\sigma_1-\sigma_2)^2+(\sigma_2-\sigma_3)^2+(\sigma_3-\sigma_1)^2}{2}}
```

とも計算できる。純粋な静水圧状態では $\mathbf{s}=\mathbf{0}$ なので $\sigma_{\mathrm{vm}}=0$ になる。このことは「応力がゼロ」を意味しない。例えば $\boldsymbol{\sigma}=100\mathbf{I}\ \mathrm{MPa}$ は全成分が $100\ \mathrm{MPa}$ だが、von Mises 応力はゼロである。

一般の二階テンソル $\mathbf{A}$ の第2主不変量は $I_2=\tfrac12\{[\mathrm{tr}(\mathbf{A})]^2-\mathrm{tr}(\mathbf{A}^2)\}$ である。偏差応力では $\mathrm{tr}(\mathbf{s})=0$、かつ応力は対称なので、$I_2(\mathbf{s})=-\tfrac12\mathbf{s}:\mathbf{s}$ となる。塑性論で使う記号 $J_2$ は慣例として正の量 $J_2=\tfrac12\mathbf{s}:\mathbf{s}$ と定義する。したがって、一般テンソルの第2主不変量と同じ式ではなく、符号も含めて区別する。

### CAEで確認すること

von Mises 応力を降伏応力と比べる前に、材料モデルが J2 型か、出力が積分点値か節点平均値か、単位が一致するかを確認する。接触端・拘束端・鋭い角のピークは、主応力・反力・変形形状・メッシュ依存性と併せて読む。相当応力は方向情報を圧縮した指標なので、き裂や層間破壊などでは主応力、応力成分、局所座標系の値も必要になる。

## Phase 2 の出口

同じ応力状態でも座標成分は変わる一方、主応力、平均応力、$J_2$、von Mises 応力は変わらないと説明できることを目標とする。次のPhaseでは、弾性テンソルの対称性、等方性、材料座標と異方性へ進む。
