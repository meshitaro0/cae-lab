# Phase 1 — CAE結果を読むための材料力学：応力・ひずみは何を表すのか

## 入口：コンターの一色を力学へ戻す

LS-DYNAなどで見るvon Mises応力、主応力、ひずみ、塑性ひずみのコンターは、物理場そのものの写真ではない。離散化、数値積分、材料更新、表示処理を通じた計算結果である。本Phaseの問いは次である。

> その色は、どの物理量を、どこで、どの仮定のもとに計算した値なのか。

```text
外力・拘束
 -> 平衡を満たす節点変位
 -> 要素内のひずみ
 -> 構成則による応力
 -> 積分点の派生量
 -> 外挿・平均を含むコンター表示
```

本文ではこの鎖を右から左へたどる。演習は [Phase 1 演習ノートブック](../../notebooks/Phase1.ipynb) で行う。

## 1. 応力：面を通じた内力の局所表現

任意の面で物体を切ると、その面を通じて内力が伝わる。面積に依存する合力ではなく局所状態を表すため、単位面積当たりの表面力を考える。単位法線ベクトルを $\mathbf{n}$、その面の表面力を $\mathbf{t}(\mathbf{n})$ とする。

面の向きが変われば表面力も変わるため、応力はベクトル一つでは表せない。Cauchyの定理により、面の法線を表面力へ写す二階テンソル $\boldsymbol{\sigma}$ が存在し、

```math
\mathbf{t}(\mathbf{n})=\boldsymbol{\sigma}\mathbf{n}
```

と書ける。ここで $\mathbf{n}$ と $\mathbf{t}$ は3成分ベクトル、$\boldsymbol{\sigma}$ は $3\times3$ 行列で表現できる二階テンソルである。有限次元ベクトル空間では、線形写像と基底を選んだ表現行列は一対一に対応する。ただし応力は座標系を変えると成分が変換される幾何学的な対象であり、行列はその座標表示である。

通常の連続体では角運動量保存から $\boldsymbol{\sigma}=\boldsymbol{\sigma}^T$ となる。詳しい定義は[用語集](../glossary.md#cauchy応力)を参照する。

### CAEで確認すること

高い応力を見つけたら、まず積分点値か節点平均値か、拘束・荷重導入部に近いか、メッシュを細かくして値がどう変わるかを確認する。荷重伝達経路とは、外力が拘束反力へ至るまでに、どの部材・断面・接触を通るかという力の流れである。反力の釣合い、変形形状、断面力の大きさを合わせて確認する。

## 2. ひずみ：FEMが解く変位から得られる量

FEMで基本未知量になるのは、通常は節点変位である。連続体の変位場を $\mathbf{u}(\mathbf{x})$ と書く。微小変形ではひずみテンソルを

```math
\boldsymbol{\varepsilon}
=\frac{1}{2}\left(\nabla\mathbf{u}+\nabla\mathbf{u}^T\right)
```

と定義する。剛体回転は材料の変形ではないため、変位勾配の対称成分だけをひずみとする。一様な棒の $u(x)=\varepsilon x$ では、$du/dx=\varepsilon$ となり、軸ひずみはこの三次元定義の一次元版である。

要素内では、変位を形状関数行列 $\mathbf{N}$ と節点変位ベクトル $\mathbf{d}$ で

```math
\mathbf{u}_h=\mathbf{N}\mathbf{d}
```

と近似する。下添字 $h$ は、要素サイズ $h$ をもつメッシュで離散化した近似場であることを表す慣用記号である。空間微分を取ると、

```math
\boldsymbol{\varepsilon}_h=\mathbf{B}\mathbf{d}
```

となる。$\mathbf{B}$ は $\mathbf{N}$ の空間微分を集めた「ひずみ–変位行列」である。次のPhaseで導出する。[形状関数](../glossary.md#形状関数)と[積分点](../glossary.md#積分点)も参照する。

## 3. 構成則：ひずみから応力への材料モデル

釣合いだけでは応力と変位の関係は決まらない。材料モデルである構成則が必要になる。等方・均質・微小ひずみ・線形弾性を仮定した場合、

```math
\boldsymbol{\sigma} = \lambda\,\mathrm{tr}(\boldsymbol{\varepsilon})\mathbf{I}
+2\mu\boldsymbol{\varepsilon}
```

である。$\lambda$ と $\mu$ はLamé定数で、$E$ と $\nu$ から定まる。導出は「等方な線形写像に許される形」を使ってPhase 2で扱う。

この仮定を外すと、異方性では方向により材料応答が変わり、不均質では位置により材料定数が変わる。大変形ではひずみ・応力の定義と平衡の記述を更新する。これらはPhase 3以降と非線形FEMで順に扱う。

$\sigma=E\varepsilon$ は、側面自由の一軸応力状態などに縮約した特殊な関係であり、万能式ではない。同じ軸方向の変形でも横方向を拘束すれば応力状態は変わる。

## 4. 主応力：応力テンソルの固有値

主応力 $\sigma_i$ と主方向 $\mathbf{q}_i$ は

```math
\boldsymbol{\sigma}\mathbf{q}_i=\sigma_i\mathbf{q}_i
```

の固有値・固有ベクトルである。主方向を座標軸に取ればせん断成分が消える。主応力は新しい力ではなく、同じテンソルを固有な座標系で読んだ値である。主応力が座標成分によらないことは、応力状態をテンソルとして扱う理由の一つである。

von Mises応力はここでは導入しない。これは特定面の実在応力ではなく、偏差応力の第2不変量から作られるスカラー指標である。Phase 2で不変量、Phase 5でJ2塑性との関係を導く。

## Phase 1 の出口

コンターを見たとき、少なくとも「節点変位から得たひずみに材料モデルを適用した積分点量であり、表示には外挿・平均があり得る」と説明できることを目標とする。次に、テンソルの座標変換と不変量へ進む。
