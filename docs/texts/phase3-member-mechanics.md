# Phase 3 — 材料力学の再導出：3次元応力から部材の軸・曲げ・ねじり・座屈へ

## 入口：CAEの応力を、なぜ一本の式で見積もれるのか

ソリッド要素のCAEは、物体内部の応力テンソルを多数の積分点で計算する。一方、材料力学では棒や梁を一本の線として扱い、$\sigma=N/A$、$\sigma=-My/I$、$\tau=T\rho/J$ のような式で応力を見積もる。両者は別の力学ではない。材料力学は、細長い三次元物体の変形と応力分布に仮定を置き、断面内の情報を少数の量へ圧縮した部材理論である。

本Phaseの問いは次である。

> 軸力・曲げ・ねじり・座屈の式は、どの仮定から導かれ、CAE結果のどこまでを説明できるか。

演習は [Phase 3 演習ノートブック](../../notebooks/Phase3.ipynb) で行う。

## 1. 共通の出発点：断面の応力を合力へ縮約する

部材の軸を $x$ 軸、断面内の座標を $y,z$ とする。断面 $A$ 上の応力分布から、軸力とモーメントを積分で作る。

```math
N=\int_A \sigma_{xx}\,dA,
\qquad
M_z=-\int_A y\,\sigma_{xx}\,dA,
\qquad
T=\int_A (y\tau_{xz}-z\tau_{xy})\,dA
```

$N$ はスカラーの軸力、$M_z$ は $z$ 軸まわりの曲げモーメント、$T$ は $x$ 軸まわりのトルクである。$\sigma_{xx}$ は軸方向の垂直応力、$\tau_{xy}=\sigma_{xy}$ と $\tau_{xz}=\sigma_{xz}$ はせん断応力成分であり、いずれもCauchy応力テンソルの成分である。ここでは $N>0$ を引張、$M_z>0$ のとき $y>0$ 側が圧縮となる符号規約を使う。ソフトウェアの断面力の符号は、要素座標とともに確認する。

この積分は、分布している表面力を静力学的に等価な合力と合モーメントへ置き換えている。逆に、$N,M_z,T$ だけから三次元応力分布を一意には復元できない。以下の公式は、断面内分布の形を運動学と構成則で仮定して初めて得られる。

## 2. 軸力：$\sigma=N/A$ と $\delta=NL/(EA)$

長さ $L$、一定断面積 $A$ の直線棒を考える。軸方向変位をスカラー場 $u(x)$ とする。次を仮定する。

1. 棒は細長く、荷重は断面の図心軸に沿って作用する。
2. 各断面はほぼ一様に伸び、$\varepsilon_{xx}=du/dx$ で表せる微小ひずみである。
3. 材料は均質な線形弾性体で、ヤング率 $E$ は一定、$\sigma_{xx}=E\varepsilon_{xx}$ である。
4. 側面は自由で、荷重導入部から十分離れた領域を考える。

軸力 $N$ が断面内で一様な軸応力を作るなら、断面の釣合いから

```math
N=\int_A\sigma_{xx}\,dA=\sigma_{xx}A
\quad\Longrightarrow\quad
\sigma_{xx}=\frac{N}{A}
```

となる。構成則とひずみ–変位関係をつなぐと

```math
\frac{du}{dx}=\varepsilon_{xx}=\frac{\sigma_{xx}}{E}=\frac{N}{EA}
```

である。$N,E,A$ が一定なら、両端の相対変位は

```math
\delta=u(L)-u(0)=\int_0^L\frac{N}{EA}\,dx=\frac{NL}{EA}
```

となる。$EA$ は軸剛性であり、力を変位勾配へ結び付ける。断面や材料が位置で変わる場合は $\delta=\int_0^L N(x)/[E(x)A(x)]\,dx$ と積分する。

### 仮定を外すと何が変わるか

偏心荷重なら曲げが重なり、穴や段差の近傍では応力は一様でなくなる。荷重導入部の局所分布はSaint-Venantの原理により十分離れると減衰するが、距離の目安は形状に依存する。塑性化すれば $E$ 一定の構成則は使えず、Phase 5の材料点更新が必要になる。

### CAEとの接続

ビーム要素の軸力 $N$ は断面合力であり、ソリッド要素の $\sigma_{xx}$ は局所応力である。比較するときは、ソリッドの断面応力を積分した $N$、拘束反力、外力が釣り合うかを先に確認する。節点平均されたピーク応力を $N/A$ と直接比較するだけでは、荷重導入部や応力集中を混同しやすい。

## 3. 曲げ：平面保持から $\sigma_{xx}=-M_zy/I_z$ を作る

### 3.1 変形の仮定

Euler–Bernoulli梁では「変形前に軸へ垂直だった平面断面は、変形後も平面を保ち、変形した軸へ垂直である」と仮定する。断面のせん断変形を無視する仮定である。

$w(x)$ を $y$ 方向のたわみを表すスカラー場、$\kappa_z(x)$ を $z$ 軸まわりの曲率を表すスカラー場とする。微小回転・微小たわみでは、符号規約を $\kappa_z=d^2w/dx^2$ として、図心を通る中立軸から距離 $y$ の繊維の軸ひずみは

```math
\varepsilon_{xx}(x,y)=-y\kappa_z(x)
```

となる。$y=0$ では伸び縮みがなく、これが中立軸である。均質な線形弾性体なら

```math
\sigma_{xx}(x,y)=E\varepsilon_{xx}(x,y)=-Ey\kappa_z(x)
```

となり、応力は中立軸からの距離に比例する。

### 3.2 断面の釣合い

図心軸を選べば $\int_A y\,dA=0$ なので、純曲げによる軸力はゼロである。$z$ 軸まわりの断面二次モーメントを

```math
I_z=\int_A y^2\,dA
```

と定義する。$I_z$ は長さの4乗の次元をもつスカラーで、断面積が中立軸からどれだけ離れて分布するかを表す。モーメントの釣合いは

```math
M_z=-\int_A y\sigma_{xx}\,dA
=E\kappa_z\int_A y^2\,dA
=EI_z\kappa_z
```

だから、

```math
\kappa_z=\frac{M_z}{EI_z},
\qquad
\sigma_{xx}=-\frac{M_z}{I_z}y
```

を得る。$EI_z$ は曲げ剛性である。外縁 $|y|=c$ で応力絶対値が最大となり、断面係数 $Z=I_z/c$ を使えば $|\sigma_{xx,\max}|=|M_z|/Z$ と書ける。

梁の釣合いから分布荷重 $q(x)$、せん断力 $V(x)$、曲げモーメント $M_z(x)$ は、採用した符号規約の下で微分関係をもつ。ここでは大きさに注目し、片持ち梁の自由端に集中荷重 $P$ が働く例では、固定端から $x$ の位置で $|M_z(x)|=P(L-x)$ である。$EI_z w''=M_z$ を境界条件とともに2回積分すると、自由端たわみの大きさは

```math
|w(L)|=\frac{PL^3}{3EI_z}
```

となる。

### 仮定を外すと何が変わるか

短く厚い梁では断面せん断変形を無視できず、Timoshenko梁が必要になる。複合材や異種材料断面では中立軸と図心が一致しない場合がある。大回転では $w''$ をそのまま曲率とする線形化が破れ、塑性化すれば応力分布も直線ではなくなる。穴、フィレット、荷重点、拘束端の局所ピークは梁公式の対象外である。

### CAEとの接続

ビーム要素では、軸力・せん断力・曲げモーメントと断面上の評価点応力を区別する。シェルやソリッドでは局所座標の $\sigma_{xx}$ を厚さ・断面方向に確認し、純曲げ領域でほぼ直線分布になるかを見る。変位比較では、せん断変形を含む要素とEuler–Bernoulli式の差が、メッシュ誤差とは限らない。

## 4. ねじり：円形軸で $\tau=T\rho/J$ が成り立つ理由

長さ $L$ の円形軸にトルク $T$ を加える。$\phi(x)$ を断面のねじれ角を表すスカラー場、$d\phi/dx$ を単位長さ当たりのねじれ角とする。円形断面では、断面が剛体的に回転し、軸方向の反りを生じないSaint-Venantねじりを考えられる。中心から距離 $\rho$ の点の工学せん断ひずみは

```math
\gamma_{x\theta}=\rho\frac{d\phi}{dx}
```

である。$\gamma_{x\theta}$ はスカラーの工学せん断ひずみ、$G$ はせん断弾性係数であり、線形弾性なら $\tau_{x\theta}=G\gamma_{x\theta}$ だから、せん断応力は半径に比例する。

極断面二次モーメントを

```math
J=\int_A \rho^2\,dA
```

と定義する。円形断面に対するトルクの釣合いは

```math
T=\int_A \rho\tau_{x\theta}\,dA
=G\frac{d\phi}{dx}\int_A\rho^2\,dA
=GJ\frac{d\phi}{dx}
```

なので、

```math
\frac{d\phi}{dx}=\frac{T}{GJ},
\qquad
\tau_{x\theta}=\frac{T\rho}{J}
```

を得る。一定断面・一定トルクなら全ねじれ角は $\phi(L)-\phi(0)=TL/(GJ)$ である。半径 $R$ の中実円断面では $J=\pi R^4/2$、外半径 $R_o$、内半径 $R_i$ の円管では $J=\pi(R_o^4-R_i^4)/2$ である。

### 仮定を外すと何が変わるか

上式で幾何学的な極断面二次モーメント $J$ をそのまま「ねじり定数」として使えるのは円形・円環断面である。非円形断面では断面が反り、せん断応力分布も $\rho$ に比例しない。薄肉開断面、拘束ねじり、端部近傍では反り応力が重要になる。CAEでは、トルク反力だけでなく、断面の反り、局所座標のせん断成分、端部から離れた領域を確認する。

## 5. 座屈：強度ではなく平衡経路の安定性

長く真直ぐな柱に圧縮力 $P>0$ が働く。横たわみを $w(x)$ とし、微小なたわみが生じた状態を考える。圧縮力はたわみに比例した付加曲げモーメントを作り、梁の曲率関係と組み合わせると、符号規約を整理した固有方程式は

```math
EI\frac{d^2w}{dx^2}+Pw=0
```

となる。$P$ はスカラーの圧縮軸力、$w(x)$ は横変位のスカラー場、$I$ は座屈する曲げ面に対応する断面二次モーメントである。両端ピン支持では $w(0)=w(L)=0$。一般解

```math
w(x)=C_1\sin(kx)+C_2\cos(kx),
\qquad k^2=\frac{P}{EI}
```

に境界条件を課すと、ゼロでない変形が存在する条件は $\sin(kL)=0$ である。最小の固有値 $kL=\pi$ からEuler座屈荷重

```math
P_{\mathrm{cr}}=\frac{\pi^2EI}{L^2}
```

を得る。支持条件は有効長係数 $K$ へまとめ、一般に

```math
P_{\mathrm{cr}}=\frac{\pi^2EI}{(KL)^2}
```

と書く。理想的な固定–固定で $K=0.5$、固定–自由で $K=2$、ピン–ピンで $K=1$ が基準値である。ただし実際の結合部をどの値に対応させるかは、回転拘束の剛性を見て判断する。

断面二次半径 $r=\sqrt{I/A}$ と細長比 $\lambda=KL/r$ を使えば、臨界平均応力は $\sigma_{\mathrm{cr}}=\pi^2E/\lambda^2$ となる。$r$ は長さ、$\lambda$ は無次元スカラーである。二方向で $I$ が異なる柱は、通常、小さい $I$ の軸まわりに座屈しやすい。

### 線形固有値座屈解析が答えること・答えないこと

線形固有値座屈解析は、基準荷重パターンを何倍すると理想化した平衡状態が分岐するかと、その座屈モードを返す。初期不整、残留応力、接触状態の変化、材料非線形、荷重経路、大変形後の耐荷力を直接は予測しない。固有モードの振幅は任意であり、実変位ではない。

実構造の耐荷力を評価する場合は、測定値や規格に基づく初期不整を固有モード等で与え、幾何学的非線形を有効にした解析を検討する。短柱では材料降伏や局部座屈がEuler座屈より先に起こり得る。これは「von Mises応力が降伏値未満だから座屈しない」という推論が成り立たない理由でもある。

## 6. 四つの理論をCAE検証へ使う

部材公式は、CAEを置き換えるものではなく、入力・出力・モデル化を検算する低次元モデルである。

| 現象 | 主要な断面量 | 主要な剛性 | まず比較するCAE量 | 典型的な破綻要因 |
| --- | --- | --- | --- | --- |
| 軸 | $N$ | $EA$ | 反力、断面力、平均 $\sigma_{xx}$、伸び | 偏心、断面急変、塑性 |
| 曲げ | $M$ | $EI$ | たわみ、断面力、厚さ方向 $\sigma_{xx}$ | せん断変形、局所応力、大回転 |
| 円形軸ねじり | $T$ | $GJ$ | 回転角、トルク反力、$\tau_{x\theta}$ | 非円形断面、反り拘束、端部効果 |
| Euler座屈 | $P$ | $EI$ と $KL$ | 固有値、モード、非線形荷重–変位 | 初期不整、塑性、局部座屈、支持剛性 |

差が出たときは、次の順で切り分ける。

1. 単位、軸方向、局所座標、断面諸量 $A,I,J$ を一致させる。
2. 外力と反力、断面力が釣り合うか確認する。
3. 比較位置を荷重導入部・拘束端・断面急変から離す。
4. 部材理論に含めなかった変形（せん断、反り、大回転）をCAEが含むか確認する。
5. 要素定式化、メッシュ、積分点値と節点平均値の違いを調べる。
6. 材料・幾何・接触の非線形性が必要か判断する。

## Phase 3 の出口

軸・曲げ・ねじり・座屈について、公式を暗記するのではなく、運動学の仮定、構成則、断面の釣合い、境界条件のどこから式が出たかを説明できることを目標とする。また、CAEとの差を単なる「誤差」とせず、局所三次元効果、要素理論、境界条件、非線形性のどれを疑うべきか切り分けられることを目指す。

次のPhase 4では、軸力を受ける1Dバーを最小例として、連続体の釣合いを弱形式へ変換し、形状関数で離散化して要素剛性 $\mathbf{K}_e=\int\mathbf{B}^T\mathbf{D}\mathbf{B}\,d\Omega$ を組み立てる。
