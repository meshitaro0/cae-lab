# 学習者プロフィール

このファイルは教材を設計・改訂する際の唯一の参照点である。学習ログから得た継続的な知見で更新する。個人を評価するための記録ではなく、教材の説明粒度・順序・演習形式を調整するための設計情報として扱う。

## 背景と強み

- 自動車CAE関連部門の技術者。FEM/CAE、LS-DYNA、サロゲートモデル、CAE自動化、データ解析を実務で扱う。
- 物性物理・量子化学計算・数値計算の経験がある。Python、Fortranを日常的に使う。
- 数式・線形代数・数値計算を避けず、「何を離散化し、何を未知量にしているか」を理解したい。
- 応力、ひずみ、主応力、Mises応力、塑性ひずみなどのCAE出力には実務経験がある。

## 到達したい状態

CAEで表示される量について、定義、導出、物理的意味、前提、適用限界、FEM内での計算位置を、ひと続きの説明として自力で語れること。公式を再生することではなく、解析結果を力学の言葉で評価できることを目標とする。

## 教材設計の原則

- 初学者扱いで基本を省きすぎず、既知の公式の反復にも時間を使いすぎない。「知っているがつながっていない」前提で設計する。
- **直感 → 定義 → 導出 → 物理的意味 → 数値実験 → FEM/CAEとの接続 → 適用限界**を、内容に応じて往復する。
- 数式中の記号と本文の記法を統一する。例：$\sigma_{xx}$、$u(x)=\varepsilon x$。
- 新しい記号・添字・演算子は初出で型（スカラー、ベクトル、テンソル、行列）と役割を明示する。
- 仮定を列挙するだけで終わらせず、仮定を外すと何が変わるかと、扱うPhaseを予告する。
- 用語だけで飛ばさない。本文の流れを壊す説明は用語集へのリンクを置く。

## 演習と対話の好み

- 演習は本文に混在させず、答案欄付きのJupyter Notebookとして配布する。
- 記述、数式、Python実験を同じノートブック内で提出・採点できる形式を好む。
- 問いは曖昧にせず、期待する成果物・小問・確認観点を明示する。
- 正解の数値だけでなく、結果の物理的説明を評価する。
- コーディングは式をそのまま転記するだけでなく、入力設計、一般化、検証条件を自分で決める余地を含める。段階的な穴埋めから始め、理解後は小さな関数や検証器を設計する課題へ進む。

## 更新ルール

- 一回の感想を恒久的な特性とみなさない。異なる教材で繰り返し観測された傾向のみを原則として本文へ昇格する。
- 現在の理解度・未解決の疑問は `learning-log.md` に記録し、ここには安定した設計判断だけを残す。
- 更新時は、根拠となる学習ログの日付をコミットまたは変更履歴に残す。
