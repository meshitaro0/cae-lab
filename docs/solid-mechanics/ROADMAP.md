# 固体力学トラック：CAE結果から逆算する固体力学ロードマップ

## 学習の流れ

| Phase | 中心の問い | 主な教材・演習の成果 |
| --- | --- | --- |
| 1. 応力・ひずみ | コンターの一色は何か | 応力・ひずみ・構成則を、積分点出力まで追う |
| 2. テンソル・不変量 | 主応力やMisesは何を表すか | 座標変換、主値、静水圧・偏差分解、不変量 |
| 3. 材料力学の再導出 | 軸・曲げ・ねじり・座屈はなぜこの式か | 仮定から導く部材理論と適用限界 |
| 4. FEM | なぜ $\mathbf{K}=\int\mathbf{B}^T\mathbf{D}\mathbf{B}\,d\Omega$ になるか | 1Dバーから始める最小FEM |
| 5. 塑性 | 相当応力・相当塑性ひずみは何か | J2塑性、流れ則、硬化、材料点更新 |
| 6. 実務CAE | 出力値の根拠と限界をどう評価するか | LS-DYNA等の結果レビューと検証計画 |

## 各Phaseの完成条件

各Phaseは、以下が揃った時点で完了とする。

1. `texts/` に導出・仮定・CAE接続を含む本文がある。
2. `notebooks/solid-mechanics/` に答案欄付きの演習ノートブックがある。
3. 学習者の解答とフィードバックが `learning-log.md` に記録されている。
4. フィードバックを踏まえた改訂判断が `TEACHING_LOOP.md` の運用に従って残っている。採点・フィードバックの文書は `reviews/` に置く。

### 次回の教材設計方針

次回の演習作成では、共通試験条件と関数引数を名前・説明で区別し、派生係数を計算する場所と外側の定数を利用してよい範囲を明示する。材料変更への対応を要求する場合は引数だけを変える検証も先に指定する。定型の入力検査は配布し、負荷条件・比較量・物理的な検証に自力設計を集中させる。導出で既知として使える式と到達点、比較する時点または変化傾向も明記する（[学習ログ](learning-log.md)の2026-09-24記録）。

比較量は差の絶対値・ノルム・相対差を式で指定する。表で保証した条件は前提として扱い、独立した一般レビューへ切り替える設問ではその旨を明記する。EPS等の定義を確認させる場合は「出力量の定義」を観点として指定し、採点時に要件を追加しない。
