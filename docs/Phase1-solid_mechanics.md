# Phase 1 — CAE結果を読むための材料力学：応力・ひずみは何を表すのか

## この教材の入口

LS-DYNA や一般の FEM ポスト処理で、要素の **von Mises stress**、主応力、ひずみ、塑性ひずみのコンターを見る。Phase 1 の問いは、次である。

> その色は、どの物理量を、どこで、どの仮定のもとに計算した値なのか。

材料力学の公式を順番に復習するのではない。まず CAE で既に扱っている出力を起点とし、そこから「内力」「応力」「ひずみ」「構成則」へ戻る。以降の FEM、塑性、実務結果評価の共通言語を作ることが目的である。

## 到達目標

この Phase の終わりに、次を自分の言葉と式で説明できるようにする。

- 応力コンターは節点の力ではなく、積分点で評価される局所的な Cauchy 応力を可視化したものである（表示時の節点外挿・平均は別処理である）。
- ひずみは変位の差ではなく、その空間勾配の対称成分である。
- 単軸の `sigma = E epsilon` は、三次元の構成則を強い仮定で縮約した特殊な場合である。
- 主応力は応力テンソルを「せん断成分が消える座標系」で読むための固有値である。
- 結果の値だけでは妥当性を判断できず、境界条件、メッシュ、積分点、材料モデル、微小変形・線形弾性などの仮定まで確認する必要がある。

## 全体の地図

```text
外力・拘束
  -> 平衡を満たす変位 u
  -> 変位勾配からひずみ epsilon
  -> 材料モデルから応力 sigma
  -> 応力の派生量（主応力、Mises など）
  -> 積分点値をポスト処理してコンター表示
```

FEM はこの流れを有限個の自由度で近似している。Phase 1 では右向きに計算する前に、コンターから左向きにたどる練習をする。

## Unit 1 — コンターの一色を分解する

### ケース：ブラケット根元の高い Mises 応力

「赤い領域がある」だけでは、まだ物理的な主張にならない。最初に次の問いへ答える。

1. その値はどの要素のどの積分点で計算されたか。
2. 要素内の変位から、どのようにひずみが得られたか。
3. そのひずみへ、どの材料モデルが適用されたか。
4. 表示値は積分点値そのものか、節点への外挿・平均値か。
5. 荷重導入、拘束、接触、メッシュ依存の特異性はないか。

**重要な区別**：コンターは物理場そのものの写真ではない。離散化、数値積分、材料更新、表示処理を経た「計算結果の表現」である。

### 演習：結果レビューの質問表

手元の解析結果を一つ選び、上の5問を埋める。埋められない項目は「結果を信頼できない」のではなく、次にモデル・出力設定・要素定式化を確認すべき箇所である。

### CAEへの接続

- 要素中心値、積分点値、節点平均値を混同しない。
- 拘束端や点荷重近傍のピークは、降伏判定に直結させず、収束性と荷重伝達経路を先に見る。

## Unit 2 — 力が応力になる必然性

部材を任意の面で切断すると、切断面の反対側から力が伝わる。面積が大きくなれば伝達力も通常は増えるため、局所状態を表すには合力ではなく面積当たりの量が必要になる。

切断面の単位法線を `n` とすると、その面に作用する表面力（traction）を `t(n)` と書く。Cauchy の定理により、ある二階テンソル `sigma` が存在して

```math
\mathbf{t}(\mathbf{n}) = \boldsymbol{\sigma}\mathbf{n}
```

となる。

### なぜ応力はベクトルではないのか

同じ材料点でも、切る面の向きを変えると伝わる力の向きと大きさが変わる。応力は「面の向き `n` を入力して traction `t` を返す線形写像」なのであり、ベクトル一つでは表せない。

```math
\boldsymbol{\sigma} =
\begin{bmatrix}
\sigma_{xx} & \tau_{xy} & \tau_{xz}\\
\tau_{yx} & \sigma_{yy} & \tau_{yz}\\
\tau_{zx} & \tau_{zy} & \sigma_{zz}
\end{bmatrix}
```

偶力を持たない通常の連続体では角運動量保存から `sigma = sigma^T` となる。対称だから6成分で足りるが、「6個の独立なスカラー」ではなく、座標変換で互いに混ざる一つのテンソルである。

### チェック問い

- `sigma_xx` が大きいことだけで、その点が危険だといえないのはなぜか。
- 法線 `n` を反転したとき、traction はどう変わるか。
- 応力の単位が Pa であることは、何を意味するか。

## Unit 3 — 変位からひずみへ：FEM がまず解くもの

FEM の基本未知量は、多くの場合、節点変位である。連続体では変位場を `u(x)` とし、微小変形では

```math
\boldsymbol{\varepsilon}
= \frac{1}{2}\left(\nabla\mathbf{u}+\nabla\mathbf{u}^{T}\right)
```

でひずみを定義する。対称成分だけを取るのは、剛体回転をひずみ（材料の変形）と数えないためである。

### 1D の復習を三次元へ戻す

一様な棒では `u(x)=epsilon x` であり、`du/dx = epsilon` となる。よく知る軸ひずみは、上式の一次元版である。三次元では、伸縮だけでなく、直交していた線分の角度変化（せん断ひずみ）も必要になる。

### CAEへの接続

要素内では形状関数 `N` を使い、変位を `u_h = N d` と近似する。よって

```math
\varepsilon_h = B d
```

となる。`B` は変位の空間微分を取る演算子を、要素形状と形状関数で離散化したものである。応力・ひずみが積分点で扱われる理由は、`B` と材料応答をそこで数値積分するためである。

---

## Unit 4 — 構成則：ひずみから応力を決める仮定

平衡式だけでは、変位・ひずみ・応力の関係は閉じない。材料固有の関係である構成則が必要になる。

等方・均質・微小ひずみ・線形弾性を仮定すると、

```math
\boldsymbol{\sigma} = \lambda\,\mathrm{tr}(\boldsymbol{\varepsilon})\mathbf{I}
+ 2\mu\boldsymbol{\varepsilon}
```

となる。`lambda, mu` は Lamé 定数で、実務では多くの場合 `E, nu` で指定する。

```math
\mu = \frac{E}{2(1+\nu)}, \qquad
\lambda = \frac{E\nu}{(1+\nu)(1-2\nu)}
```

### 単軸公式はどこから来るか

`sigma = E epsilon` は万能式ではない。側面が自由な一軸応力状態、線形弾性、微小ひずみ等の条件で得られる縮約形である。反対に、ひずみを横方向に拘束するかどうかで `sigma_yy, sigma_zz` は変わる。これは「材料定数」と「境界条件」を分けて考える訓練になる。

### 演習：同じ軸ひずみ、異なる拘束

`epsilon_xx = 0.001` の立方体を考える。

1. 横方向を自由にする一軸応力状態。
2. 横方向ひずみをゼロにする一軸ひずみ状態。

両者で発生する応力、ひずみエネルギー、CAEで想定されるモデル化場面を比較する。式を当てはめる前に、どちらが厚肉部・長い棒・平面ひずみ断面に近いかを説明する。

## Unit 5 — 主応力：テンソルを材料点の固有な方向で読む

主応力 `sigma_i` と主方向 `q_i` は固有値問題

```math
\boldsymbol{\sigma}\mathbf{q}_i = \sigma_i\mathbf{q}_i
```

の解である。主方向に垂直な面ではせん断 traction が消え、その法線応力が主応力になる。

### 誤解を避ける

- 主応力は「新しい力」ではない。同じ応力状態を、せん断が消える座標系で読んだ値である。
- 最大主応力だけで延性材料の降伏を語れるとは限らない。破壊様式と材料モデルに依存する。
- 座標成分は回転で変わるが、主応力の組は材料点の応力状態に固有である。

### Pythonで確認する

ランダムな対称応力テンソルを作り、`numpy.linalg.eigh` で主応力・主方向を求める。主方向基底に変換した応力の非対角成分が数値誤差程度になることを確認する。

## Unit 6 — ここでまだ Mises を使わない理由

von Mises 応力は応力テンソルから得る便利なスカラーだが、テンソルそのものではなく、実在する特定面の応力でもない。これを理解するには、応力を静水圧成分と偏差成分に分け、不変量と J2 降伏条件を導く必要がある。

それは Phase 2（テンソル・不変量）と Phase 5（塑性）で扱う。Phase 1 では、Mises 応力を「材料モデルの降伏判断に使われる、応力状態の偏差成分に基づく指標」として保留する。公式を先取りして暗記しないことが重要である。

## 最小実験：1要素が計算する量を再現する

この実験ではソルバを作ることが目的ではない。入力と出力の間にある物理を確認する。

1. 対称なひずみテンソル `epsilon` を用意する。
2. 工学せん断ひずみを含む Voigt 表記へ変換する。
3. 等方線形弾性の構成行列 `D` で `sigma_v = D @ epsilon_v` を計算する。
4. 応力テンソルに戻し、対称性と主応力を確認する。
5. `E`、`nu`、拘束条件のどれを変えたかを明示して、結果の変化を説明する。

**V&V の問い**

- `epsilon = 0` なら `sigma = 0` になるか。
- ひずみを2倍にすると応力も2倍になるか（線形弾性の範囲で）。
- 等方的ひずみでせん断応力はゼロか。
- 応力テンソルは対称か。

## Phase 1 の出口

ここまでで、CAE出力を次の鎖として説明できる。

```text
境界条件・荷重
 -> 節点変位
 -> 要素内のひずみ B d
 -> 構成則による応力
 -> 積分点値とポスト処理
```

次の Phase では、この鎖の「応力テンソルをどう読むか」を深掘りする。座標変換、主値、静水圧・偏差分解、不変量を導き、Mises応力を正体から理解する。
